# Pixel Perfect Marketplace

**ACTIVE CAPSULE CONTEXT**



**User Intent**

The user intends to build a system, likely a web application, with specific features and functionalities.



**Key decisions made**

• The database, sign-in, and visual style are set up.

• The pages to be built include the AI problem finder, worker profiles with proof of work, bookings, and dashboards.

• The backend is being set up first, followed by the pages.

• The marketplace pages are live with sample data, and the user has previewed them.

• The sign-in page with different user types and other works will be built next.



**Constraints or requirements identified**

• The system is being built as a Pixel Perfect Replica.

• The backend is being set up before creating the pages.



**Technicalities/Details**

• The system is being built with a focus on setting up the backend before creating the pages.

• The user is actively building the system, with the assistant providing guidance and support.

• The backend is connected.

• The database is being set up with profiles, roles, skills, proof-of-work portfolios, courses, bookings, and reviews.

• The user has previewed the marketplace pages, which include:

  • Home: hero with a problem box, how it works, and top-rated workers

  • Problem finder: describes what's wrong and suggests the trade, urgency, rough cost, and matching workers

  • Workers: browse and search six tradespeople with ratings and verified badges

  • Worker profiles: proof-of-work portfolio with job photos, reviews, and a booking form

  • Bookings: track jobs with statuses and quotes

  • Dashboard: a worker's view with earnings, upcoming jobs, and portfolio progress

• The style is warm paper-and-ink with a terracotta accent.

• Lovable Cloud will be set up for real sign-in, profiles, and bookings once the user is happy with the pages.
